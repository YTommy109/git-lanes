# 登録済みリポジトリのサイドバー表示 — 設計仕様

**日付**: 2026-04-26
**ブランチ**: feat/repo_manager
**対応仕様**: F-06（リポジトリ切り替え）、US-04

---

## 概要

アプリ起動のたびにリポジトリパスを入力する手間を解消するため、登録済みリポジトリの一覧を常設サイドバーに表示する。サイドバーはすべての画面（ウェルカム・グラフ）で共通表示し、クリック一発でリポジトリを切り替えられるようにする。

---

## 機能要件

1. **リポジトリ一覧表示** — DB に登録済みのリポジトリ名を左サイドバーに一覧表示する。
2. **ナビゲーション** — リポジトリ名をクリックすると `/repos/{repo_id}/graph` に遷移する。
3. **現在リポジトリのハイライト** — グラフ画面では現在表示中のリポジトリをハイライトする。
4. **新規登録フォーム** — サイドバー内にパス入力フォームを置き、`POST /api/repos` で登録できる。ウェルカム画面のフォームはサイドバーに委譲し、ウェルカム画面は説明テキストのみにする。
5. **全画面共通** — `base.html` にサイドバーを組み込み、すべての画面で表示する。

---

## アーキテクチャ

```
base.html（全画面共通レイアウト）
├── 左サイドバー
│   ├── リポジトリ一覧（<a href="/repos/{id}/graph">）
│   │   └── 現在 repo_id と一致するエントリに is-active クラス
│   └── パス入力フォーム（POST /api/repos、action="/api/repos"）
└── メインコンテンツブロック
    ├── welcome.html（説明テキストのみ）
    └── graph.html（SVG グラフ＋詳細パネル）
```

---

## データフロー

```
GET / または GET /repos/{repo_id}/graph
  └─ html.py
       ├─ cache_repo.list_repositories(session) → repos リスト
       ├─ 現在の repo_id（グラフ画面のみ、ウェルカムは None）
       └─ TemplateResponse("base.html 経由", {"repos": repos, "current_repo_id": ...})
```

サイドバーは Jinja2 でサーバーサイドレンダリングする。JavaScript は使用しない。

## インターフェース定義

### `list_repositories(session: Session) -> list[Repository]`

- DB の `repository` テーブルから全件取得する。
- 並び順: `name` 昇順。
- 0 件のときは空リスト `[]` を返す。

### テンプレートコンテキスト追加項目

| キー | 型 | 説明 |
|-----|----|------|
| `repos` | `list[Repository]` | 全登録リポジトリ（サイドバー表示用） |
| `current_repo_id` | `str \| None` | 現在表示中の repo_id。ウェルカム画面は `None` |

---

## エラーハンドリング

- **無効パス入力**: 既存の `api.py` バリデーション（pygit2 検証）が 400 を返す。サイドバーフォームに変更なし。
- **重複登録**: 既存の重複チェックが同一リポジトリの graph へリダイレクトする。

## テスト戦略

### 単体テスト（`tests/unit/test_cache_repo.py`）

| ケース | 期待結果 |
|--------|---------|
| リポジトリが複数登録済みのとき `list_repositories` を呼ぶ | 全件が name 昇順で返る |
| リポジトリが 0 件のとき `list_repositories` を呼ぶ | 空リストが返る |

### E2E テスト（`tests/e2e/test_sidebar.py`）

| ケース | 期待結果 |
|--------|---------|
| リポジトリ登録済みの状態でウェルカム画面を開く | サイドバーにリポジトリ名が表示される |
| サイドバーのリポジトリ名をクリックする | グラフ画面に遷移する |
| グラフ画面で現在のリポジトリ | サイドバー該当エントリがハイライトされる |
| サイドバーのフォームに有効なパスを入力して送信する | 登録されてグラフ画面に遷移し、サイドバーに追加される |
