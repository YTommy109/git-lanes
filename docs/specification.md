# Git Lanes - 製品仕様書

## 概要

Git Lanes は、Git リポジトリのブランチ構造をグラフィカルに可視化する **Mac デスクトップアプリケーション**です。
Electron が FastAPI サーバーをサブプロセスとして内包し、`.app` バンドルとして配布します。
開発が継続しても表示速度が劣化しないよう、SQLite キャッシュとインクリメンタルな差分更新を核心設計とします。

---

## 解決する課題

### 既存 Git GUI ツールの問題点

- リポジトリに直接問い合わせてグラフを毎回生成するため、コミット数が増えるにつれ表示が重くなる
- 全コミットを一度に読み込むため、初期表示が遅い

### Git Lanes のアプローチ

1. グラフ生成に必要なデータを SQLite に永続化する
2. 差分があった場合のみ Git リポジトリに問い合わせ、SQLite を更新する
3. SQLite のデータのみを参照してグラフを描画する
4. 表示範囲を「現在のトップから N コミット分」に限定し、それ以前はページネーション / 無限スクロールで遅延ロードする

## 機能要件

### コア機能

| ID | 機能 | 説明 |
| --- | --- | --- |
| F-01 | ブランチグラフ表示 | ブランチの分岐・マージを SVG で可視化する |
| F-02 | コミット詳細表示 | コミットハッシュ・メッセージ・作者・日時を表示する |
| F-03 | 増分読み込み | 次ページを hidden で先読みし、スクロールで表示域に入った時点で visible に切り替える。ボタン操作は不要 |
| F-04 | 差分キャッシュ更新 | リポジトリに変更があった場合のみ SQLite を更新する |
| F-05 | ブランチフィルタ | 表示するブランチを絞り込む |
| F-06 | リポジトリ切り替え | 複数リポジトリを選択して表示を切り替える |
| F-07 | Mac アプリとして起動 | `.app` バンドルをダブルクリックするだけで起動できる |
| F-08 | リポジトリをフォルダ選択で追加 | Mac のネイティブダイアログでフォルダを選び、リポジトリを登録する |
| F-09 | ウェルカム画面 | 初回起動時にウェルカム画面を表示し、フォルダを開くボタンを提供する |
| F-10 | 画面分割レイアウト | 左ペイン：ブランチグラフ、右ペイン：コミット詳細（ハッシュ・メッセージ・作者・日時）を表示する |
| F-11 | リモートブランチ表示切り替え | リモートブランチの表示をオン/オフで切り替える |
| F-12 | リモートブランチの同期状態表示 | ローカルと同じコミットは塗り潰し円、異なるコミットは波線円をブランチ名のプレフィックスに表示する |
| F-13 | タグ表示 | コミットに付与されたタグをグラフ上に表示する。オン/オフを切り替えられる |

### 表示仕様

- **初期表示コミット数**: 直近 50 コミットを上限として表示する
- **1 ページあたりのコミット数**: 50 件（追加ロード単位）
- **グラフ方向**: 上が新しい（縦スクロール）

### 非機能要件

| 項目 | 目標値 |
| --- | --- |
| 初期表示速度 | 2 秒以内（SQLite キャッシュ済み状態） |
| キャッシュ差分更新速度 | 1 秒以内（差分 100 コミット以下） |
| 対応リポジトリ規模 | コミット数 100,000 件まで |
| 配布形式 | macOS 向け `.app` バンドル（Apple Silicon / Intel 両対応） |
| 起動時間 | アプリ起動からグラフ表示まで 3 秒以内（キャッシュ済み状態） |

## ユーザーストーリー

### US-00: アプリを初めて起動する

```
As a 開発者
I want to アプリを起動したらウェルカム画面でリポジトリを開けるようにしたい
So that 使い始めに迷わず最初の操作に進める
```

### US-01: ブランチグラフを閲覧する

```
As a 開発者
I want to Git リポジトリのブランチ構造をグラフで確認したい
So that ブランチの分岐・マージの流れを視覚的に把握できる
```

### US-02: 過去のコミットを遡る

```
As a 開発者
I want to スクロールするだけで過去のコミットが継続して表示されてほしい
So that ボタンを押さずにブランチの歴史をシームレスに追うことができる
```

### US-03: コミット詳細を確認する

```
As a 開発者
I want to グラフ上のコミットをクリックして右ペインに詳細情報を表示したい
So that グラフを見ながら変更内容・作者・タイムスタンプを素早く把握できる
```

### US-04: 複数リポジトリを切り替える

```
As a 開発者
I want to 複数のリポジトリを登録して切り替えたい
So that プロジェクトをまたいでブランチ状況を確認できる
```

## テスト方針

### 単体テスト

- スタイル: AAA（Arrange / Act / Assert）形式でブロック分け
- カバレッジ目標: **85〜90%**（意味のあるテストケースで達成すること）
- 言語: コメントは必ず日本語

### 統合テスト・E2E テスト

- フレームワーク: **Playwright**（`playwright/test`）
- スタイル: ガーキン記法（Given / When / Then）でブロック分け
- コメント言語: 日本語（ガーキンキーワードは英語のまま）
- Electron アプリは `_electron.launch()` で直接起動してテストする

### E2E テストの重点項目

| 項目 | 詳細 |
| --- | --- |
| 画面遷移 | ページ間のナビゲーションが正常に動作すること |
| 動的要素 | ボタン・メニューなどのインタラクションが正常に動作すること |
| 操作制御 | ボタン / メニューの disable / enable 状態が正しく切り替わること |

> **注意**: E2E ではビジネスロジックの網羅的な値検証は行わない。ハッピーパスと操作制御に集中する。
