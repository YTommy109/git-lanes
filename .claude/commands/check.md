プロジェクトの品質チェックをすべて実行し、結果を報告する。

## 実行するチェック

以下を順番に実行する。失敗しても最後まで実行してから結果をまとめて報告する。

### 1. Lint

```bash
uv run ruff check src/
```

### 2. フォーマット

```bash
uv run ruff format --check src/
```

### 3. 単体テスト + カバレッジ

```bash
uv run task test
```

カバレッジが 85% を下回る場合は警告する。

### 4. ファイル行数チェック

`src/` 以下の Python ファイルで 150 行を超えるものを検出する。

```bash
find src -name "*.py" | xargs wc -l | awk '$1 > 150 && $2 != "total"' | sort -rn
```

150 行超のファイルがあれば分割を提案する。
